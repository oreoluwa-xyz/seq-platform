All sixteen CC controls now fit in two rows in the compact desktop strip, including the minimum window size. The web workshop uses the same compact CC tiles, with responsive columns.

Live track mute feedback is shared across desktop and web: a steady red indicator with M / Muted means the whole track is muted; a pulsing red indicator with ± / Partial mute means some lanes or layers are muted. Reduced-motion preferences disable pulsing. The new firmware reports explicit mute state, including wrapped melody/drum tracks. Older firmware and stale connections show mute status as unavailable.

Ctrl + Backslash hide/show, live MIDI, TEMP status, and saved window placement are retained. Install the included firmware to enable live mute feedback.
