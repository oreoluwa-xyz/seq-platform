# SEQ v0.1.3 preview

- Fix macOS desktop MIDI connections that detect the keyboard but time out without receiving SysEx data.
- Select Chromium's legacy CoreMIDI backend automatically at startup, preserving other disabled-feature flags. No special launch command is needed.
- Restore live keyboard and TEMP status in the desktop Performance view.
- Add a packaged smoke-test check for the macOS MIDI backend selection.

Verified against a connected Keychron V1 Max after a normal app restart. Existing v0.1.2 firmware already supports this fix; no reflash is required.

The desktop installer is an Apple Silicon macOS preview with an ad-hoc signature, not Developer ID signed or notarized.
