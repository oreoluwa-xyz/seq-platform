## Changes since v0.1.11

- **Shift + Space + F1–F12** toggles the entire track with one tap, including all drum lanes and any melodic layer. Individual lane/layer mute choices are preserved on unmute. Track mutes persist in saves, backups and TEMP; old projects load with this gate off. Sounding notes and queued repeats stop immediately. Space + Backspace clears all track and individual mutes.

- Hold **Ctrl + Space** and turn the knob to change the current track's actual loop length by one step. Add either **Shift** for 16-step increments. Clockwise expands with empty space; counterclockwise shortens the track. Shortening trims notes, drum hits/modifiers and CC automation beyond the new endpoint; expanding again does not restore them.
- **Space + =** doubles the exact track length and repeats its content into the added half. **Space + Shift + =** doubles with an empty extension. Existing Tab duplication shortcuts remain available. Duplication is rejected when it would exceed capacity.
- **Space + F** toggles playhead Follow. Its indicator appears on F while Space is held. The manual, live follow hint and keyboard reference show the new mappings.
- **Space + knob** still adjusts swing. **Ctrl + knob** without Space still adjusts global tempo.
- Tap **Ctrl + Space** for Scale or **Ctrl + Shift + Space** for Harmony; these hardware shortcuts open on Space release when no knob turn occurred. Turning the knob suppresses the editor action. Finish held edits and disarm recording before resizing.
- Preserve the compact Ableton-friendly layout, simultaneous rhythm/palette view, and stable controls during live polling.

## Distribution and hardware checks

The Apple Silicon macOS 13+ preview app bundles Studio, the local firmware service and matching Keychron V1 Max ANSI encoder firmware **2026.10.16.2**. The DMG is ad-hoc signed and unnotarized, as in the existing preview workflow. Automatic app updates are not included.

Installing the app does not flash the keyboard. Back up the current project before a separate local firmware installation. Hardware flashing, USB reconnection, musical behavior and macOS/Ableton window-placement checks remain separate from automated tests and compilation. This release does not claim those physical checks were performed.
