## Changes since v0.1.5

- Keep the Euclidean rhythm visible beside the palette in the short desktop performance strip. Select a note or chord to highlight its source hits and see their count; recorded overrides are excluded. Highlights describe palette assignments before variation.
- Open Palette automatically when capture or palette editing begins. Preserve explicit tab choices, keyboard focus, and clickable controls during live polling.
- Add per-entry chord qualities to the Euclidean palette, including fixed qualities and scale-aware Auto triads/sevenths. Edit one slot or all slots from the keyboard or UI.
- Add reversible melodic variations: reordered or random pitch selection, rotation, mutation, chord voicing, reroll and lock, with immediate or next-bar application to one or all melodic tracks. Original material is preserved.
- Apply accumulator offsets to chords as a group, and support temporary global loop-length changes.
- Show project capacity, save status and TEMP readiness in the companion.
- Fix stored-rhythm restoration and reduce stack pressure during project/TEMP serialization. Add regression coverage for restore, global loop length, chord palettes, variation, and live UI behavior.

## Distribution

The desktop installer includes the Studio UI and matching firmware. The static web UI is published at https://oreoluwa-xyz.github.io/seq-studio/ui/ and versioned in the seq-studio v0.1.11 release. This release does not flash connected keyboards automatically.
