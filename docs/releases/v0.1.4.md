The desktop performance view now defaults to a compact bottom strip for use alongside a DAW. All twelve track indicators remain visible, TEMP status is quieter, and the enlarged step grid aligns with the circular rhythm view. Euclid and CC controls follow the keyboard mode; Workshop and the keyboard guide remain accessible.

Ctrl + Backslash (\) globally hides or shows SEQ while keeping MIDI connected. A toolbar Hide button provides the same quick access. Bundled firmware adds pass-through for this shortcut during sequencer, Euclid and CC modes. The shortcut requires this updated firmware; the keyboard already flashed with the local shortcut build also supports it.

The macOS live MIDI fix from v0.1.3 is retained. Window placement and pinning are preserved.
