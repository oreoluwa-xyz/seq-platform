# SEQ v0.1.2 preview

- TEMP: Enter + Esc starts or keeps a performance variation. Esc restores immediately. Shift + Esc toggles restoration at the next global 16-step bar; purple Esc blinks while queued.
- Web Studio and desktop Performance view show TEMP readiness, active/queued state, and shortcut guidance. Project transfers and saving are unavailable while TEMP is active.
- Chord-bank firmware modules are removed. The chord editor, recorded polyphonic notes, and offline harmony drafts remain available. Older saved bank tracks retain their recorded notes.
- Ctrl + Euclid prints melodic loops and the selected drum lane. Short melodic cycles repeat to the track length; long cycles clip. Palette notes can be removed individually.
- Matching firmware adds TEMP telemetry. Earlier firmware shows shortcut guidance without claiming live TEMP state.

The desktop installer is an Apple Silicon macOS preview with an ad-hoc signature, not Developer ID signed or notarized.
