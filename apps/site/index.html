A FEW THINGS TO KNOW

Before you
press play.

Do I need the keyboard to try SEQ?

You can try the rhythm sketch and explore Studio’s offline drafts without hardware. To use the hardware sequencer, you need a supported keyboard running SEQ firmware.

Which keyboard is supported?

The current firmware target is the Keychron V1 Max ANSI with encoder. Other keyboards are not supported targets yet. SEQ is an independent project, not an official Keychron product.

Does SEQ make sound on its own?

The keyboard sends USB MIDI to a DAW, software instrument, or compatible MIDI host connected to a synth. It isn’t a synthesizer. The small demo on this page uses browser-generated sounds only for illustration.

Can I use it with Ableton or VCV Rack?

SEQ can send MIDI to software through your MIDI setup. Dedicated Ableton and VCV Rack integrations are planned; they are not available products today.

Is it ready for my live set?

SEQ is in active development. Test your exact firmware, routing, and setup before relying on it on stage. Keep project backups, and check the manual for differences between firmware versions.

Where should I start with the hardware?

Read the interactive manual to understand the controls and the repository’s development instructions for the toolchain. Firmware installation requires a local setup; opening this website does not flash your keyboard.
